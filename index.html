A WORKSPACE THAT DISAPPEARS

界面退后一步，
判断向前一步。

Siftroom 不是缩小版图库，也不要求先建立目录。它把选片、焦点判断和轻量显影留在同一张光台上，然后在不需要时安静退场。

01 / KEYBOARD-FIRST

决定从不打断浏览

方向键持续前进。P 保留、X 拒绝，再按一次取消；U 清除旗标。Command 与 Shift 多选后，评级、标签和调整统一作用于整组照片。

再按即取消

标记是可逆决定，不是一次性命令。

原生触控板

胶片条保留惯性与空间记忆，不强制居中。

批量但可撤销

整组选片、调整和删除都进入清晰的撤销链。

02 / PHOTOGRAPHIC PROCESS 01

不是加深颜色，
是重新组织光。

对比度围绕照片自己的中灰轴展开，高光、阴影、白色与黑色各自作用于不同亮度区域；色彩变化保护明度与肤色，让批量统一也保留照片原本的层次。

03 / LOCAL FILTER LAB

你的风格，
也是一个文件。

导入 .siftfilterpack 即可使用一组 RGB 与蒙板滤镜。所有滤镜都只包含声明式参数，不执行第三方代码；你也可以在滤镜工坊中制作、导出，再通过任何社区分享。

  • 七款官方摄影示例，显示真实渲染结果
  • 线性、径向、亮度、颜色与画笔蒙板
  • 每个滤镜都能配置自己的快捷键

04 / COMPARE MODE

哪张更锐？
放在一起看。

按 C 进入无干扰双图比较。两张照片共享缩放与平移，快速定位到人脸或眼部；连拍优选不再依赖来回切换的短暂记忆。

  • 同步 100% 检查
  • 人脸与眼部定位
  • 对焦峰值辅助

05 / PRIVATE INTELLIGENCE

06 / RULE-BASED DELIVERY

选完，
按你的规则交付。

批量导出 JPEG，设置质量、最长边与色彩空间。基础名称加数字序列，导出前逐字预览最终文件名。需要署名时，按 ⌘⇧W 一键叠加水印再导出。
