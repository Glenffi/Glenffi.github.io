A WORKSPACE THAT DISAPPEARS

界面退后一步，
判断向前一步。

Siftroom 不是缩小版图库，也不是堆满面板的编辑器。它只保留摄影师做决定时真正需要的东西，然后在不需要时安静消失。

01 / KEYBOARD-FIRST

决定从不打断浏览

方向键持续前进。P 保留、X 拒绝，再按一次取消；U 清除旗标。Command 与 Shift 多选后，评级、标签和调整统一作用于整组照片。

再按即取消

标记是可逆决定，不是一次性命令。

原生触控板

胶片条保留惯性与空间记忆，不强制居中。

批量但可撤销

整组选片、调整和删除都进入清晰的撤销链。

02 / COMPARE MODE

哪张更锐？
放在一起看。

按 C 进入无干扰双图比较。两张照片共享缩放与平移，快速定位到人脸或眼部；连拍优选不再依赖来回切换的短暂记忆。

  • 同步 100% 检查
  • 人脸与眼部定位
  • 对焦峰值辅助

03 / ONE-COLUMN INSPECTOR

判断所需，一列到齐

RGB 与亮度直方图、曝光裁切、完整 EXIF 和非破坏性调整收在一列里。面板可以固定，也可以在照片需要更多空间时完全退场。
