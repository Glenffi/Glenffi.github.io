A WORKSPACE THAT DISAPPEARS

界面退后一步，
判断向前一步。

一次拍摄，可以有清楚的来路和去处。导入时留下校验记录，项目里接着上次的进度；浏览、比较、降噪与交付仍围绕照片展开。无需建立全局图库，也不强制改变你的文件夹习惯。

01 / A VERIFIED START

带回照片，
也带回一份安心。

先浏览记忆卡或文件夹里的照片，再选择工作盘。每个文件复制后都读回校验；需要第二份备份时，选择另一个卷，副本也独立检查。来源照片保持原样。

01 / VERIFY复制之后，再读一次

逐文件 SHA-256 校验，可保存校验报告。第二份备份建议使用另一块物理磁盘。

02 / RESUME中断，也接得回来

暂停或退出后从导入记录继续。已校验的工作副本可以先开始选片。

03 / ORGANIZE一次拍摄，同一套规则

RAW、JPEG 与 XMP 成组命名；元数据模板保存作者、版权与关键词，支持跳过相同内容。

02 / A PLACE FOR EACH SHOOT

05 / ON-DEVICE AI DENOISE

少一些噪点，
判断留给你。

模型随 App 内置，照片在这台 Mac 上处理。先启用降噪，再放大到原始像素检查细节；调整强度、亮度与颜色噪点，找到你愿意留下的质感。

设置满意后，可批量同步给已保留照片，或直接处理并导出。

效果因素材和噪声而异。以 100% 细节对比，决定适合这张照片的强度。

06 / LOCAL FILTER LAB

你的风格，
也是一个文件。

导入 .siftfilterpack 即可使用一组 RGB 与蒙板滤镜。所有滤镜都只包含声明式参数，不执行第三方代码；你也可以在滤镜工坊中制作、导出，再通过任何社区分享。

  • 七款官方摄影示例，显示真实渲染结果
  • 线性、径向、亮度、颜色与画笔蒙板
  • 每个滤镜都能配置自己的快捷键

07 / COMPARE MODE

哪张更锐？
放在一起看。

按 C 进入无干扰双图比较。两张照片共享缩放与平移，快速定位到人脸或眼部；连拍优选不再依赖来回切换的短暂记忆。

  • 同步 100% 检查
  • 人脸与眼部定位
  • 对焦峰值辅助

08 / PRIVATE INTELLIGENCE

机器帮你折叠，
照片不离开 Mac。

Vision 在设备本地计算相似特征、连拍关系、人脸与眼部位置，并为组内照片给出可读的清晰度排序。相似照片折叠成更少的判断单元，分析结果可随项目复用，原片始终不上传。

09 / RULE-BASED DELIVERY

选完，
按你的规则交付。

批量导出 JPEG，设置质量、最长边与色彩空间。基础名称加数字序列，导出前逐字预览最终文件名。需要署名时，按 ⌘⇧W 一键叠加水印再导出；需要客户挑片时，导出一份可勾选的 PDF 选片包，客户保存发回后可自动导入选择。
