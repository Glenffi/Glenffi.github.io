CHANGELOG / THE WORK CONTINUES

每次变化，
都留下依据。

这里记录 Siftroom 的公开版本变化。官网首页只介绍产品本身，具体更新留在这里。

2026.10.281.1.1

ENGLISH / SIMPLIFIED CHINESE

用熟悉的语言，
继续选片。

  • App 新增英语界面，默认跟随系统，也可在通用设置中选择语言，重新启动后生效。
  • 菜单、导入、项目、降噪、地图、导出、客户选片 PDF、权限与错误提示同步本地化。
  • 官网新增右上角中英切换，保留当前页面和章节；支持说明、隐私政策与版本记录均提供英文。
2026.10.271.1.0

IMPORT / PROJECTS / LOCAL DENOISE

从记忆卡，
到值得留下的照片。

  • 新增导入中心：从记忆卡或文件夹预览导入，复制后逐文件读回 SHA-256 校验。
  • 可选第二盘备份并独立校验，支持暂停、退出后继续和导出校验报告。来源文件保持原样。
  • RAW、JPEG 与 XMP 成组命名，支持内容去重，以及作者、版权、关键词等元数据模板。
  • 新增项目工作区，记住选片进度、调整与上次浏览位置，复用本地分析；文件夹移动后可重新定位。
  • 新增本地 AI 降噪，支持整体强度、亮度与颜色噪点控制、原始像素前后对比，以及已保留照片批量导出。
  • 优化导入界面、日期与选项选择、降噪状态反馈和细节对比交互。
2026.10.181.0.4

CLIENT SELECTION / PDF DELIVERY

让客户勾选，
摄影师自动接回。

  • 新增“导出客户选片包”，生成带水印预览、说明和可勾选 PDF。
  • 客户只需打开 PDF、勾选照片、保存并发回，不需要网页、账号或 JSON 文件。
  • 摄影师可用“导入客户选片”自动把客户勾选的照片标记为保留。
  • 文件菜单补齐打开、导出、水印导出、导入选片、Finder 和取消操作的快捷键提示。
2026.10.161.0.3

WATERMARK / PREVIEW

先看到效果，
再按下导出。

  • 导出面板新增实时水印预览，设置变化会立即反映到当前照片。
  • 水印支持在预览图上自由拖动，九宫格按钮保留为快速定位入口。
  • 可一键隐藏设置面板专注查看预览，位置、大小与不透明度继续跨会话记忆。
2026.10.131.0.2

WATERMARK / DELIVERY

署名，只需一次按键。

  • 新增水印导出：按 ⌘⇧W 一键为照片叠加签名水印并导出。
  • 内置 siftroom 签名水印，也可在导出面板中换成自己的图片。
  • 九宫格位置、缩放与不透明度可调，并随导出设置保存。
  • 修复滤镜编辑器在新版 Swift 工具链下的兼容性问题。
2026.09.021.0.1

DEVELOP / FILTER / RELIABILITY

显影更像显影，
选择依然轻盈。

  • 新的摄影显影引擎：自适应中灰对比度、分区高光阴影、色相保护与柔和高光肩部。
  • 清晰度、去雾、降噪、锐化和暗角升级为明度域、多尺度与区域蒙板处理。
  • 加入本地滤镜包、真实摄影预览、蒙板滤镜工坊、导入导出和滤镜快捷键。
  • 旋转裁切自动放大并裁掉边角，编辑预览与最终渲染方向保持一致。
  • 打开空目录时进入清晰空态，并持续监听之后加入的照片。
2026.08.271.0.0

FIRST LIGHT

第一张光台。

  • 文件夹直开、RAW 两阶段预览、方向键浏览与原生触控板胶片条。
  • 保留/拒绝、星级、颜色标签、多选批量操作与撤销删除。
  • 同步双图比较、本地 Vision 分组、人脸眼部定位、清晰度排序与对焦峰值。
  • EXIF、RGB/亮度直方图、非破坏调整、XMP sidecar、预设与规则化 JPEG 导出。
