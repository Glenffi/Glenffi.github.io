01 / START

Getting started

Open your photos

Drag photos or a folder into Siftroom, or press ⌘O. Enable the optional Finder Service in System Settings.

Start culling

Browse with Left/Right Arrow. P picks, X rejects; press the same key again to clear. U always clears the flag.

Compare detail

Select two photos and press C. Pinch to zoom and pan with two fingers; both photos stay in sync.

Batch delivery

Adjust a selection or apply a preset together, then export with a base name and padded sequence.

Add a watermark

Preview watermark changes live in Export. Press ⌘⇧W to enable watermark export, then drag the mark or use the quick anchors.

Client picks

Choose Export Client Selection in Export. Clients check the PDF, save and return it; import the returned PDF to flag the matching originals.

Use local filters

Open Window → Filter Library to import a .siftfilterpack file, or create RGB and mask-based filters in the workshop.

Lightweight development

Exposure, tone, white balance, clarity, dehaze, denoising and sharpening are non-destructive.

IMPORT / VERIFY / CONTINUE

Start from a card.
Or open a folder directly.

Choose a card or folder in File → Import Photos… (⌘I). Preview source thumbnails, select a work disk and project, and set naming rules and optional metadata. You can still press ⌘O to review a folder without creating a project.

How do verification and the second copy work?

Each file is copied to a staging location, then read back and verified with SHA-256 before being published as a completed primary. A second copy is made from that verified primary and checked independently. Choose another volume for the backup, preferably on a separate physical disk so one disk failure cannot affect both copies. Verification does not replace a long-term backup strategy.

What if an import is interrupted? When can I eject the card?

Continue unfinished jobs from import history. Siftroom rechecks completed files and restarts an unfinished file; reauthorize source or backup folders if needed. Wait until all required copies have completed and passed verification before ejecting your card. Siftroom does not delete source photos or format cards.

Do naming, deduplication or metadata change my source files?

Sources stay unchanged. RAW, JPEG and XMP files are renamed as a group at the destination. Optional content deduplication reuses identical imported groups without overwriting review or edit state. Templates fill empty fields by default. Original XMP is archived separately and working XMP merges creator, copyright and keywords. The second-disk backup retains source bytes.

Will I lose progress if I move a photo folder?

Open File → Projects… (⌘⇧P), select the project and choose Relocate… to point to its new photo folder. Flags, edits, the last viewed photo and local analysis stay with the project. The list is a lightweight index; removing a project entry does not delete photos.

ON-DEVICE AI / NATIVE PIXELS

Denoise first. Then compare.

Expand AI Denoise in the inspector, increase strength and wait for processing. Choose Compare… to inspect the selected region at native pixels. Click the overview or use the arrows to move. Comparison is unavailable when denoising is off or still processing.

Are photos uploaded? Do I need a model download?

The model is bundled with the app. AI denoising, decoding, review analysis and export run locally without photo uploads or an account. It processes decoded images; time and results depend on image size, noise and Mac performance.

How do luminance, color and batch controls work?

Expand Luminance and Color to control how much of each type of noise is processed. Reduce luminance processing to retain more grain. Batch… can copy denoise settings to picked photos in the current folder, or process and export that set. Check the scope before exporting.

Why do some regions use protective processing?

The model may create unusual texture in very dark, smooth regions. Siftroom checks output and uses conservative denoising for clearly abnormal regions, with a notice in Compare. Inspect at native pixels before applying. This is not a specialized astrophotography denoiser or RAW mosaic reconstruction tool.

03 / FAQ

FAQ

Why does a RAW file show only its embedded preview?

Support depends on the camera, compression and macOS decoder version. Siftroom tries the system RAW engine, then LibRaw. If neither supports the file, it keeps the embedded preview and identifies its source rather than presenting it as a full RAW rendering.

Do flags and edits change my originals?

No. Ratings, labels and edits are stored locally, or in a matching XMP sidecar when enabled. Pixel changes are written to new files only when exported.

How do I position a watermark?

Open watermark settings while browsing, or use the live preview in Export. Drag the mark freely or use the nine quick anchors. Position, size and opacity are remembered.

How do I send photos to a client for selection?

Choose Export Client Selection in Export. Send the generated selection PDF to your client. They check photos, save and return the PDF. Choose File → Import Client Picks… in Siftroom to mark the corresponding originals.

Why is Open in Siftroom missing from Finder?

Put Siftroom in Applications and launch it once. Go to System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders, and enable Open in Siftroom.

Why will the filmstrip not scroll?

It scrolls only when its content is wider than the available space. Place the pointer over it and swipe with two fingers horizontally or vertically. If all collapsed groups fit, there is no extra distance to scroll.

Can I recover removed photos?

Delete moves photos to the macOS Trash. Press ⌘Z immediately to undo, or restore them from the Trash. Siftroom watches the folder and updates its contents.

How do I import, create or share filters?

Open Window → Filter Library to import a local .siftfilterpack file, or create a filter in the workshop. Exported packs are ordinary files you can share through forums, cloud drives or messaging apps. Siftroom has no upload marketplace.

Can filter packs execute third-party code?

No. Packs contain only supported declarative RGB, LUT and mask parameters. Size, type and integrity are checked before import. Packs contain no scripts, plug-in binaries or executable models.

Are adjustment values compatible with Adobe Camera Raw?

No. Siftroom uses its own processing engine: exposure in EV, region-based tone controls and adaptive midtone contrast. It is designed for quick review and batch consistency, without claiming to reproduce Adobe's proprietary camera profiles or Process Version.

Does Siftroom upload photos or collect usage data?

No. Image analysis and processing run locally, without accounts, ads or third-party analytics. The website stores contact details and your question only when you choose to submit a support request.
