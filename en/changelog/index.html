CHANGELOG / THE WORK CONTINUES

Every change.
A clear record.

A record of Siftroom's version changes. The home page describes the product; this page records what changed.

2026.10.281.1.1

ENGLISH / SIMPLIFIED CHINESE

Your language.
The same focused review.

  • The app now supports English, following system preferences or a language chosen in General settings. Quit and reopen to apply a change.
  • Localized menus, imports, projects, denoising, maps, exports, client PDFs, permission descriptions and errors.
  • Switch website language in the upper-right corner while keeping the current page and section. Support, privacy and version history are available in English.
2026.10.271.1.0

IMPORT / PROJECTS / LOCAL DENOISE

From memory card
to photos worth keeping.

  • New Import Center: preview and import a card or folder, with per-file SHA-256 read-back verification.
  • Optional second-disk backup with independent verification, pause and resume, and exportable reports. Sources remain intact.
  • Grouped RAW/JPEG/XMP renaming, identical-content deduplication and metadata templates for creator, copyright and keywords.
  • New Projects: remember review progress, edits and your last photo, reuse local analysis and relocate moved folders.
  • New on-device AI Denoise with strength, luminance and color controls, native-pixel comparison and batch export of picked photos.
  • Refined import layout, date and option controls, denoise feedback and detail comparison.
2026.10.181.0.4

CLIENT SELECTION / PDF DELIVERY

Clients make their picks.
You get them straight back.

  • Export Client Selection creates watermarked previews, instructions and a checkable PDF.
  • Clients open the PDF, make picks, save and return it. No website, account or JSON files.
  • Import Client Picks automatically flags the matching originals as picked.
  • File menus now display shortcuts for opening, exporting, watermarks, client picks, Finder reveal and cancellation.
2026.10.161.0.3

WATERMARK / PREVIEW

See the result.
Then export it.

  • Live watermark preview in Export, updating as settings change.
  • Drag marks freely, or use nine quick anchors.
  • Hide settings to focus on the preview. Position, size and opacity persist between sessions.
2026.10.131.0.2

WATERMARK / DELIVERY

Your signature. One shortcut.

  • Press ⌘⇧W to add a watermark and export.
  • Start with the Siftroom signature or choose your own image.
  • Quick anchors, scale and opacity are saved with export settings.
  • Improved filter editor compatibility with the newer Swift toolchain.
2026.09.021.0.1

DEVELOP / FILTER / RELIABILITY

More photographic processing.
The same focused review.

  • New processing engine with adaptive midtone contrast, tonal regions, hue protection and gentle highlights.
  • Clarity, dehaze, denoising, sharpening and vignette use luminance, multiple scales and regional masks.
  • Local packs, real photo previews, a mask-based workshop, import/export and filter shortcuts.
  • Rotate and crop fill the frame automatically, keeping preview and export orientation consistent.
  • An empty folder now has a clear empty state and watches for newly added photos.
2026.08.271.0.0

FIRST LIGHT

First light.

  • Direct folder opening, progressive RAW previews, arrow navigation and a native trackpad filmstrip.
  • Pick/reject, ratings, color labels, multi-selection and undoable removal.
  • Linked two-up comparison, local Vision grouping, face and eye focus, sharpness ordering and focus peaking.
  • EXIF, RGB/luminance histograms, non-destructive adjustments, XMP sidecars, presets and rule-based JPEG export.
