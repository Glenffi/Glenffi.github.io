01 / START

快速开始

打开一组照片

将文件或文件夹拖进 Siftroom，或使用 ⌘O。Finder 服务可在系统设置中单独启用。

开始选片

左右方向键浏览，P 保留、X 拒绝，再按同一个键取消。U 始终清除旗标。

比较细节

选择两张照片后按 C。捏合缩放、双指平移，两张照片保持同步。

批量交付

多选照片后统一调整或应用预设，导出时可设置基础名称与数字序列。

添加水印

导出面板会实时预览水印效果。按 ⌘⇧W 开启水印导出，可直接拖动水印或使用九宫格快速定位。

客户选片

导出面板选择“导出客户选片包”，客户在 PDF 里勾选并保存发回；摄影师用“导入客户选片”自动标记原片。

使用本地滤镜

从“窗口 → 滤镜库”导入 .siftfilterpack，或在滤镜工坊中创建自己的 RGB 与蒙板滤镜。

轻量显影

检查器中的曝光、分区色调、白平衡、清晰度、去雾、降噪与锐化均为非破坏调整。

IMPORT / VERIFY / CONTINUE

从记忆卡开始，
也能直接打开文件夹。

在“文件 → 导入照片…”（⌘I）选择记忆卡或文件夹。先查看来源缩略图，选择工作盘和拍摄项目，再设置命名规则与可选元数据模板。直接用 ⌘O 打开照片文件夹仍然可用，不要求创建项目。

导入校验和第二份备份如何工作？

每个文件先复制到临时位置，写入完成后读回进行 SHA-256 校验，通过后才作为工作副本发布。第二份副本从已校验的工作副本复制，再独立读回校验。备份需选择另一卷；为了避免同一物理磁盘故障同时影响两份副本，建议使用另一块物理磁盘。校验不等同于长期备份或故障保险。

导入中断后怎么办？什么时候可以拔卡？

从导入记录中继续未完成的任务。程序会复核已完成文件，从未完成文件重新复制；需要时重新授权来源或备份目录。请等本次任务所需的副本全部完成并确认校验结果后再推出记忆卡。Siftroom 不删除来源照片，也不格式化记忆卡。

重命名、去重和元数据会改动原文件吗？

来源保持原样。RAW、JPEG 与配套 XMP 在目标中成组命名。可选内容去重会复用完全一致的已导入组，不覆盖已有选片和编辑。元数据模板默认补充空字段；原始 XMP 单独保留，工作 XMP 合并作者、版权、关键词等内容。第二盘备份保留来源字节。

移动拍摄文件夹后，项目进度会丢吗？

打开“文件 → 项目…”（⌘⇧P），选择项目并点击“重新定位…”，指向移动后的照片目录。项目记住标记、调整、上次浏览位置和本地分析。项目列表是轻量索引；移除项目记录不会删除照片。

ON-DEVICE AI / NATIVE PIXELS

降噪，先处理再对比。

在检查器展开“AI 降噪”，调高强度并等待处理完成，再点“查看对比…”。对比页按原始像素显示所选区域，点击概览图或方向按钮换区域。未启用或正在处理时，对比入口不可用。

照片会上传吗？需要额外下载模型吗？

安装包已内置模型。AI 降噪、图像解码、选片分析和导出在 Mac 本地运行，不上传照片，也不要求账号。模型处理解码后的图像，速度与效果取决于素材尺寸、噪声和 Mac 性能。

亮度与颜色、批量处理怎么用？

展开“亮度与颜色”，可分别调整两类噪点的处理比例。降低亮度噪点处理可保留更多颗粒感。“批量…”可把降噪设置同步到当前文件夹中已保留的照片，或处理并导出这批照片；导出前请核对范围。

为什么部分区域提示使用保护处理？

模型有时会在极暗、平滑区域产生异常纹理。Siftroom 检查每个处理区域，发现明显异常时改用保守降噪，并在对比页提示。建议以 100% 原始像素检查再应用；这不是专门的天文去噪或 RAW 马赛克域重建工具。

03 / FAQ

常见问题

为什么某个 RAW 只能显示嵌入预览？

RAW 支持取决于相机、压缩方式与 macOS 解码器版本。Siftroom 会先尝试系统 RAW 显影，再尝试 LibRaw；仍不支持时保留嵌入预览并明确显示来源，不会把 JPEG 预览冒充完整 RAW。

标记和调整会修改原片吗？

不会。评级、标签和调整默认保存在 Siftroom 的本地记录中；启用 XMP 时写入同名 sidecar。像素修改只在导出时生成新文件。

如何调整水印位置？

浏览时可先打开水印设置，导出面板也提供实时预览。直接拖动水印即可自由定位，也可以使用右侧九宫格按钮快速吸附到常用位置；位置、大小和不透明度会被记住。

如何把照片交给客户挑选？

在导出面板点击“导出客户选片包”。把生成的“客户选片.pdf”发给客户；客户打开 PDF 勾选、保存后发回。回到 Siftroom 后选择“文件 → 导入客户选片…”，软件会自动标记对应原片。

Finder 里“在 Siftroom 中打开”没有出现怎么办？

先将 Siftroom 放在“应用程序”目录并启动一次，然后前往系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹，勾选“在 Siftroom 中打开”。

为什么胶片条滑不动？

只有内容超出胶片条宽度时才存在滚动距离。将鼠标放在胶片条上，可使用触控板左右或上下双指滑动；折叠组全部适配一屏时不会产生位移。

删除的照片还能恢复吗？

Delete 会把照片移动到 macOS 废纸篓。立即按 ⌘Z 可撤销；也可以在废纸篓中手动放回，Siftroom 会监测目录变化并刷新。

如何导入、创建或分享滤镜？

打开“窗口 → 滤镜库”，可以导入本地 .siftfilterpack，也可以进入滤镜工坊创建滤镜。导出的滤镜包是普通文件，可通过论坛、网盘或聊天工具自行分享；Siftroom 不提供上传市场。

滤镜包会运行第三方代码吗？

不会。滤镜包只允许 Siftroom 定义的声明式 RGB、LUT 与蒙板参数，经过大小、类型和完整性校验后才会导入，不包含脚本、插件二进制或可执行模型。

基础调整是否与 Adobe Camera Raw 数值兼容？

不兼容。Siftroom 使用自己的摄影显影引擎：曝光采用 EV，高光、阴影、白色、黑色按亮度区域处理，对比度使用自适应中灰 S 曲线。它面向快速审阅和批量统一，不宣称复制 Adobe 的私有相机配置与 Process Version。

Siftroom 会上传照片或收集使用数据吗？

不会。图像分析和显影在本地完成；应用不含账号、广告或第三方分析 SDK。只有你主动提交支持表单时，网站才会保存你填写的联系邮箱和问题内容。
