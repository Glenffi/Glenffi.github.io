01 / START

快速开始

打开一组照片

将文件或文件夹拖进 Siftroom，或使用 ⌘O。Finder 服务可在系统设置中单独启用。

开始选片

左右方向键浏览，P 保留、X 拒绝，再按同一个键取消。U 始终清除旗标。

比较细节

选择两张照片后按 C。捏合缩放、双指平移，两张照片保持同步。

批量交付

多选照片后统一调整或应用预设，导出时可设置基础名称与数字序列。

使用本地滤镜

从“窗口 → 滤镜库”导入 .siftfilterpack，或在滤镜工坊中创建自己的 RGB 与蒙板滤镜。

轻量显影

检查器中的曝光、分区色调、白平衡、清晰度、去雾、降噪与锐化均为非破坏调整。

03 / FAQ

常见问题

为什么某个 RAW 只能显示嵌入预览？

RAW 支持取决于相机、压缩方式与 macOS 解码器版本。Siftroom 会先尝试系统 RAW 显影，再尝试 LibRaw；仍不支持时保留嵌入预览并明确显示来源，不会把 JPEG 预览冒充完整 RAW。

标记和调整会修改原片吗？

不会。评级、标签和调整默认保存在 Siftroom 的本地记录中；启用 XMP 时写入同名 sidecar。像素修改只在导出时生成新文件。

Finder 里“在 Siftroom 中打开”没有出现怎么办？

先将 Siftroom 放在“应用程序”目录并启动一次，然后前往系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹，勾选“在 Siftroom 中打开”。

为什么胶片条滑不动？

只有内容超出胶片条宽度时才存在滚动距离。将鼠标放在胶片条上，可使用触控板左右或上下双指滑动；折叠组全部适配一屏时不会产生位移。

删除的照片还能恢复吗？

Delete 会把照片移动到 macOS 废纸篓。立即按 ⌘Z 可撤销；也可以在废纸篓中手动放回，Siftroom 会监测目录变化并刷新。

如何导入、创建或分享滤镜？

打开“窗口 → 滤镜库”，可以导入本地 .siftfilterpack，也可以进入滤镜工坊创建滤镜。导出的滤镜包是普通文件，可通过论坛、网盘或聊天工具自行分享；Siftroom 不提供上传市场。

滤镜包会运行第三方代码吗？

不会。滤镜包只允许 Siftroom 定义的声明式 RGB、LUT 与蒙板参数，经过大小、类型和完整性校验后才会导入，不包含脚本、插件二进制或可执行模型。

基础调整是否与 Adobe Camera Raw 数值兼容？

不兼容。Siftroom 使用自己的摄影显影引擎：曝光采用 EV，高光、阴影、白色、黑色按亮度区域处理，对比度使用自适应中灰 S 曲线。它面向快速审阅和批量统一，不宣称复制 Adobe 的私有相机配置与 Process Version。

Siftroom 会上传照片或收集使用数据吗？

不会。图像分析和显影在本地完成；应用不含账号、广告或第三方分析 SDK。只有你主动提交支持表单时，网站才会保存你填写的联系邮箱和问题内容。
