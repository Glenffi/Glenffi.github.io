01 / START

下面是 Mac 的操作方式。iPhone 与 iPad 请查看“Mac 与移动端”。

快速开始

找回操作入口

鼠标靠近画布边缘时唤出操作，或按 ⌘/ 固定显示操作栏。选片、配色与合成都留在当前工作区；按 ⌘0 回到照片。

打开一组照片

将文件或文件夹拖进 Siftroom，或使用 ⌘O。Finder 服务可在系统设置中单独启用。

开始选片

左右方向键浏览，P 保留、X 拒绝，再按同一个键取消。U 始终清除旗标。

比较细节

选择两张照片后按 C。捏合缩放、双指平移，两张照片保持同步。

批量交付

多选照片后统一调整或应用预设，导出时可设置基础名称与数字序列。

添加水印

按 ⌘/ 唤出操作栏，选择“操作 → 水印与位置”，即可在浏览时调整水印和拍摄地点。导出前可再次预览，⌘⇧W 快速进入水印导出。

客户选片

导出面板选择“导出客户选片包”，客户在 PDF 里勾选并保存发回；摄影师用“导入客户选片”自动标记原片。

使用本地滤镜

从“窗口 → 滤镜库”导入 .siftfilterpack，或在滤镜工坊中创建自己的 RGB 与蒙板滤镜。

轻量显影

检查器中的曝光、分区色调、白平衡、清晰度、去雾、降噪与锐化均为非破坏调整。

MAC / IPHONE / IPAD

同一种工作流，适合不同屏幕。

Mac 使用文件夹、键盘与大屏幕；iPhone 和 iPad 优先从相册选择照片，也可以通过“文件”读取文件夹与外接存储。

手机和平板上如何打开工具？

轻点照片显示控件，再点编辑与工具。iPhone 使用底部面板，iPad 横屏使用侧边检查器。关闭面板后，回到刚才的照片。

照片和编辑会自动跨设备同步吗？

Siftroom 不提供自有云端图库或自动项目同步。可以通过你选择的文件存储、导出的照片、滤镜包和 XMP 文件在设备间传递内容。导入后请检查外部素材与调整是否完整。

移动端导出的照片保存在哪里？

照片页的保存按钮默认保存到相册。交付面板中也可以选择保存到文件；客户选片 PDF 使用系统分享或文件保存。原始照片保持不变。

在哪里看操作示例？

Mac 从「帮助 → 操作示例」打开。iPhone 与 iPad 在空白页或「照片与项目」菜单中打开「操作示例」，按手机或平板的布局学习点按、双指缩放、滑动与长按。

IMPORT / VERIFY / CONTINUE

从记忆卡开始，
也能直接打开文件夹。

在“文件 → 导入照片…”（⌘I）选择记忆卡或文件夹。先查看来源缩略图，选择工作盘和拍摄项目，再设置命名规则与可选元数据模板。直接用 ⌘O 打开照片文件夹仍然可用，不要求创建项目。

导入校验和第二份备份如何工作？

每个文件先复制到临时位置，写入完成后读回进行 SHA-256 校验，通过后才作为工作副本发布。第二份副本从已校验的工作副本复制，再独立读回校验。备份需选择另一卷；为了避免同一物理磁盘故障同时影响两份副本，建议使用另一块物理磁盘。校验不等同于长期备份或故障保险。

导入中断后怎么办？什么时候可以拔卡？

从导入记录中继续未完成的任务。程序会复核已完成文件，从未完成文件重新复制；需要时重新授权来源或备份目录。请等本次任务所需的副本全部完成并确认校验结果后再推出记忆卡。Siftroom 不删除来源照片，也不格式化记忆卡。

重命名、去重和元数据会改动原文件吗？

来源保持原样。RAW、JPEG 与配套 XMP 在目标中成组命名。可选内容去重会复用完全一致的已导入组，不覆盖已有选片和编辑。元数据模板默认补充空字段；原始 XMP 单独保留，工作 XMP 合并作者、版权、关键词等内容。第二盘备份保留来源字节。

移动拍摄文件夹后，项目进度会丢吗？

打开“文件 → 项目…”（⌘⇧P），选择项目并点击“重新定位…”，指向移动后的照片目录。项目记住标记、调整、上次浏览位置和本地分析。项目列表是轻量索引；移除项目记录不会删除照片。

ON-DEVICE AI / NATIVE PIXELS

降噪，先处理再对比。

在检查器展开“AI 降噪”，调高强度并等待处理完成，再点“查看对比…”。对比页按原始像素显示所选区域，点击概览图或方向按钮换区域。未启用或正在处理时，对比入口不可用。

照片会上传吗？需要额外下载模型吗？

安装包内置 AI 降噪模型。AI 降噪、图像解码、选片分析和导出在设备上运行。速度和效果取决于照片尺寸、噪声和设备性能。

亮度与颜色、批量处理怎么用？

展开“亮度与颜色”，可分别调整两类噪点的处理比例。降低亮度噪点处理可保留更多颗粒感。“批量…”可把降噪设置同步到当前文件夹中已保留的照片，或处理并导出这批照片；导出前请核对范围。

为什么部分区域提示使用保护处理？

模型有时会在极暗、平滑区域产生异常纹理。Siftroom 检查每个处理区域，发现明显异常时改用保守降噪，并在对比页提示。建议以 100% 原始像素检查再应用；这不是专门的天文去噪或 RAW 马赛克域重建工具。

LOCAL STUDIO / PRO

Pro 与进阶工作流

哪些功能免费，哪些需要 Pro？

Apple 照片编辑扩展、HDR 查看与导出、滤镜工坊、浏览与手动选片、导入、项目、本地 AI 降噪、基础人像精修和星轨合成免费。Pro 一次购买解锁客户选片链接、整组一致、智能选片、样片滤镜应用与保存、智能工坊、分区脸型、批量肤质、星点对齐和星轨地景保护。八款风格滤镜可免费试色，应用需单独解锁滤镜包。

如何购买或恢复 Pro？

在 Siftroom 菜单中打开“Siftroom Pro…”。购买由 App Store 处理，不需要创建 Siftroom 账号。重新安装或更换 Mac 后，使用购买时的 Apple 账户登录 App Store，再点击“恢复购买”。价格以购买页面显示为准。

智能选片会替我删除照片吗？

不会。从“工作台 → 智能选片…”（⌘⌥A）开始分析，比较组内清晰度、曝光和人脸细节。可拆分或合并分组、保留多张；确认只标记你勾选的照片，不会自动删除原片，也不会把眼部提示当作确定的闭眼结论。

智能工坊和滤镜工坊如何使用？

在「工作台 → 智能工坊」里用 Pro 匹配参考图配色，或生成主体、人物与背景蒙版，应用为可继续编辑的图层。免费滤镜工坊支持使用自己的 RAW 或 JPEG 测试图，进行多图预览、HSL 调整和三向色彩分级。

星空堆栈需要什么照片？

选择同一拍摄序列中至少两张通过评估和对齐的照片。固定三脚架拍摄时可启用地景保护，检查红色区域并用画笔或导入蒙版修正。生成新的 16 位 TIFF，保留原片。对齐失败的照片会排除并说明原因；此功能不是深空校准、星轨、HDR 或景深合成工具。

版本、交付方案和任务在哪里？

在“工作台”菜单打开照片版本、交付方案或后台任务（⌘⌥J）。版本保存不同的调整与裁切；交付方案复用导出设置。任务中心显示进度与历史。导入可继续未完成任务，星空任务中断后需要重新开始。

切换语言还需要重新启动吗？

2.0 起无需重新启动。在“设置 → 通用 → 界面语言”选择英语、简体中文或跟随系统，已打开的界面会立即更新。你自己输入或已保存的项目、模板与滤镜名称不会被翻译。

能关闭 Pro 功能建议吗？

可以。点击建议卡片的关闭按钮，或在“…”中选择“不再建议 Pro”。后者会永久关闭本机建议；已经解锁 Pro 时不会显示。

REFERENCE / REUSABLE LOOKS

从样片创建自己的滤镜

先打开要处理的照片组，再从“操作 → 样片滤镜”或“工作台 → 从样片创建滤镜…”进入。选择一张色调参考图，使用当前照片或自己的测试照片查看效果；在胶片条切换照片时，参考图与参数会保留。

免费预览和 Pro 保存有什么区别？

选择参考图、比较效果和调整参数可以免费使用。把样片滤镜应用到照片、批量应用或存为滤镜包时需要 Pro。保存后可在滤镜库中继续使用，也能导出为 .siftfilterpack 文件分享。

为什么不会和样片完全一样？

样片滤镜借鉴色彩统计和可选的明暗关系，不会复制场景、光线、景深或人物。先调整强度，再决定是否匹配明暗或保护肤色；不同题材需要结合预览判断。

换一张照片要重新选择样片吗？

不需要。当前样片与参数会保留，胶片条用于切换预览照片。需要其他照片时，可把它们加入当前工作区。

试色、应用和恢复购买

先打开一张照片。Mac 从“窗口 → 滤镜库…”进入。iPhone 和 iPad 轻触“调整”里的“滤镜”。打开“风格滤镜”标签，点任意一款即可预览。

预览时可以调强度、对比处理前后。应用八款风格需单独买断。已购买时，可用购买所用的 Apple 账户，在预览页选择“恢复购买”。

PORTRAIT / ON DEVICE

人像精修怎么用？

在哪里调整肤质和脸型？

打开一张照片，按 ⌘/ 唤出操作栏，再选择「人像精修」。调整自然磨皮、均匀肤色或轻度瘦脸。合照可先选择人物；双击预览可放大，再切换处理前后。

为什么轻度瘦脸显示不可用？

脸部侧转较大、接近画面边缘或关键点不足时，界面会显示具体原因。可以继续使用磨皮和均匀肤色。

Pro 可以批量应用哪些人像调整？

在胶片条多选照片后，可批量应用磨皮和均匀肤色。每张照片独立识别人脸，合照与识别不清的照片会被跳过。分区脸型用于逐张精修。

STAR TRAILS / STAR ALIGNMENT

星空工作区的两种模式怎么选？

我想保留星星移动的轨迹

打开固定机位连续拍摄的照片，在「操作 → 星空」中选择「星轨合成」。彗星拖尾可以调节渐隐强度与方向，强度为 0% 时使用标准星轨。预览后可导出 16 位 TIFF。

我想让星点保持为点并降低噪声

在「操作 → 星空」中选择 Pro 的「星点对齐」。先评估并对齐星点，再叠加至少两张通过检查的照片。可在处理记录查看参与帧、排除原因与对齐诊断。

星轨地景保护怎么用？

开启“保护地景 · Pro”，选择干净的地景参考帧，检查保护范围。画笔用于添加保护，橡皮擦用于减少保护；Option 临时擦除，⌘Z 撤销上一笔。其他照片继续参与天空叠加。

导出后如何继续看图或调整？

星轨导出完成后，合成视图会直接显示成片。点击“在主窗口打开”回到照片工作区继续调整；处理记录保留参与照片和输出信息。

03 / FAQ

常见问题

为什么某个 RAW 只能显示嵌入预览？

RAW 支持取决于相机、压缩方式与 系统解码器版本。Siftroom 会先尝试系统 RAW 显影，再尝试 LibRaw；仍不支持时保留嵌入预览并明确显示来源，不会把 JPEG 预览冒充完整 RAW。

标记和调整会修改原片吗？

不会。评级、标签和调整默认保存在 Siftroom 的本地记录中；启用 XMP 时写入同名 sidecar。像素修改只在导出时生成新文件。

如何调整水印位置？

浏览时可先打开水印设置，导出面板也提供实时预览。直接拖动水印即可自由定位，也可以使用右侧九宫格按钮快速吸附到常用位置；位置、大小和不透明度会被记住。

如何把照片交给客户挑选？

在导出面板点击“导出客户选片包”。把生成的“客户选片.pdf”发给客户；客户打开 PDF 勾选、保存后发回。回到 Siftroom 后选择“文件 → 导入客户选片…”，软件会自动标记对应原片。

Finder 里“在 Siftroom 中打开”没有出现怎么办？

先将 Siftroom 放在“应用程序”目录并启动一次，然后前往系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹，勾选“在 Siftroom 中打开”。

为什么胶片条滑不动？

只有内容超出胶片条宽度时才存在滚动距离。将鼠标放在胶片条上，可使用触控板左右或上下双指滑动；折叠组全部适配一屏时不会产生位移。

Mac 上删除的照片还能恢复吗？

Delete 会把照片移动到 macOS 废纸篓。立即按 ⌘Z 可撤销；也可以在废纸篓中手动放回，Siftroom 会监测目录变化并刷新。

如何导入、创建或分享滤镜？

打开“窗口 → 滤镜库”，可以导入本地 .siftfilterpack，也可以进入滤镜工坊创建滤镜。导出的滤镜包是普通文件，可通过论坛、网盘或聊天工具自行分享；Siftroom 不提供上传市场。

滤镜包会运行第三方代码吗？

不会。滤镜包只允许 Siftroom 定义的声明式 RGB、LUT 与蒙板参数，经过大小、类型和完整性校验后才会导入，不包含脚本、插件二进制或可执行模型。

基础调整是否与 Adobe Camera Raw 数值兼容？

不兼容。Siftroom 使用自己的摄影显影引擎：曝光采用 EV，高光、阴影、白色、黑色按亮度区域处理，对比度使用自适应中灰 S 曲线。它面向快速审阅和批量统一，不宣称复制 Adobe 的私有相机配置与 Process Version。

Siftroom 会上传照片或收集使用数据吗？

浏览、选片分析和图像处理在设备上进行。主动发布客户选片相册时，服务接收带水印的预览，并接收客户提交的选片结果。地图和地址解析使用 Apple 服务，支持表单处理你主动提交的信息。

在哪里设置拍摄位置？

打开照片后，在“操作 → 水印与位置 → 拍摄位置”搜索地点或地图选点，也可选择“Mac 当前定位”请求系统定位授权。位置用于写入导出的副本；Mac 当前位置不等于照片的实际拍摄地。

用链接完成客户选片

客户选片链接需要 Siftroom Mac 2.4.1 或 iPhone/iPad 1.2.1 及更新版本。

Mac

打开照片项目，在「文件」菜单选择「客户选片链接…」。

iPhone / iPad

打开项目，在「编辑与工具 → 工作台 → 交付」中选择「客户选片链接…」。

  1. 发布需要 Siftroom Pro。首次使用时通过 Apple 登录，选择照片和相册名称，再点「上传并生成链接」。上传的是带水印的 JPEG 预览，原片保留在设备上。
  2. 把链接发给客户。客户在手机或电脑浏览器打开、勾选并提交，无需安装 App 或注册。
  3. 收到结果后，打开包含对应原片的项目，查看相册结果并选「标记为保留」。如果原片缺失、重复或已变化，Siftroom 会提示核对。

每个 UTC 自然月最多发布 10 个相册，每个相册最多 300 张。链接发布后可访问 30 天，可提前撤回。请仅向参与选片的客户分享链接。

在 Apple 照片中使用 Siftroom

Mac

在「照片」中连按一张静态照片，点「编辑」，从「扩展」（…）选择 Siftroom。调整后点「存储更改」。若菜单里找不到 Siftroom，在系统设置的「照片编辑」扩展中启用。

iPhone / iPad

打开一张静态照片，轻点「编辑」和「更多」（…）。如果菜单里有「扩展」，先打开，再选择 Siftroom。调整后先在扩展里点「完成」，再在「照片」里点「完成」。

光线、色彩和五款内置滤镜均可免费使用。如果原片尚未下载，先在「照片」中把这张照片下载到设备。

选择 HDR 或 SDR 输出

使用 Siftroom 打开带有 HDR 数据的照片。要看到超出 SDR 的高光亮度，需要支持 HDR 的屏幕。

Mac

按 ⌘E 打开导出设置，在「格式」中选择所需的输出。

iPhone / iPad

打开「编辑与工具 → 工作台 → 交付」，在「格式」选好后保存到相册或文件。

  • 自动保留 HDR。兼容的 HDR 照片保存为 HEIF（.heic），普通照片保存为 JPEG。
  • HEIF · HDR。把支持的 HDR 高光保留在 HEIC 成片中。
  • JPEG · SDR。将 HDR 高光映射到标准动态范围，适合跨设备分享。

在「照片」扩展里，可在「输出」中为兼容照片选择保留 HDR 或 SDR 兼容。HDR 存回图库需系统「照片」接受 HEIC。

让同场景的照片保持一致

在主 App 打开至少两张同场景的照片。从「工作台 → 整组一致 · Pro」选择已调好的参考图，然后分析本组照片。iPhone 和 iPad 可从「编辑与工具」打开工作台。

逐张查看前后、调整整组强度，再勾选要应用的照片。在 Mac 用 ⌘Z 撤销整批。在 iPhone 或 iPad 回到浏览界面，长按照片并选「撤销上一步」。
